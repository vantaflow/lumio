## Ce qui est livré

- `TorrentPlayback` (`app/lib/torrent/torrent_playback.dart`) : magnet construit par `magnetFromInfoHash(infoHash, trackers)`, attente d'au moins une source (45 s, puis `NoPeersException`), lecture des métadonnées, choix du fichier (`fileIdx` valide, sinon le plus grand fichier lisible), URL locale du moteur ; `release()` arrête le torrent et supprime les données.
- Un seul moteur pour l'application (`torrentEngineProvider`), initialisé au premier torrent avec le cache (Go) et le débit montant (Ko/s) des réglages (`torrent_providers.dart`) ; la politique de cache complète reste à la Task 25.
- Lecteur : un flux torrent est préparé par `PlayerScreen`, puis ouvert par le chemin interne `trustedLocal: true` sur `http://127.0.0.1:...` (jamais depuis une donnée d'addon). Superposition sources, débit, % téléchargé ; perte réseau : « Connexion perdue, nouvelle tentative… » sans arrêt de l'attente ; échec : message français et « Choisir une autre source ».
- Fiche, reprise en un clic et épisode suivant lisent les torrents ; le classement `StreamPrefs` (qualité, langue, lien direct avant torrent à égalité) décide seul.

## Procédure de mesure sur la box (Step 5, à exécuter)

1. Sur le Mac : `bash scripts/disk-guard.sh`, puis builder l'APK `--target-platform android-arm` (ANDROID_HOME/JAVA_HOME du contexte) et l'installer : `adb -s 192.168.0.43:5555 install -r ...`.
2. Lancer sur le Mac le `FakeAddonServer` qui expose un flux `infoHash` Sintel (`08ada5a7a6183aae1e09d831df6748d566095a10`, trackers publics) ; l'ajouter dans l'app par son adresse privée (autorisation réseau privé).
3. Ouvrir Sintel, choisir le flux torrent ; relever en `adb logcat` : temps jusqu'aux premiers octets, jusqu'à la première image (`firstFrameMs`), pairs, débit.
4. Seek : au milieu puis dans la dernière minute (point non téléchargé), relever le délai de reprise.
5. Fermer le lecteur : dossier de téléchargement vide (`adb shell ls <cache>/lumio_torrents`).
6. Couper le Wi-Fi 20 s en pleine lecture puis le rétablir : message « Connexion perdue… », reprise sans plantage.
7. Porte 1080p (spike 0.6) : sur un torrent 1080p réel (swarm sain), le débit soutenu lu par le lecteur doit rester au moins égal au débit vidéo (ordre de 8 Mbit/s, soit 1 Mo/s) pendant 5 minutes sans rebuffering. Référence du spike : 0,39 Mo/s moyen sur Sintel ; si la porte n'est pas tenue, limiter à 720p ou envisager `dtorrent_task_v2` derrière `TorrentEngine`.
