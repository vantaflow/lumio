# Lecteur et proxy local : essai sur la box (2026-11-18)

Statut : **mesures non faites**. La box de test (192.168.0.43:5555) était injoignable (« Host is down », plusieurs tentatives). Un autre appareil Skyworth (192.168.0.20, 3,7 Go de RAM, sans Lumio) était visible dans adb ; il n'a pas été utilisé, ce n'est pas la box désignée.

À mesurer (journal `LUMIO_PLAYER`), à relancer quand la box répond :
`LUMIO_BUILD_ARGS=--dart-define=LUMIO_DEBUG_PLAYER=1 bash scripts/box-smoke.sh` puis `adb logcat -d | grep LUMIO_PLAYER`.
