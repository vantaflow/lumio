# Lecteur et proxy local : essai sur la box (2026-11-18)

Mesures faites le 2026-11-18 sur la box 192.168.0.45:5555 (APK release android-arm, `LUMIO_DEBUG_PLAYER=1`), toutes les sources via le proxy local.

Correctif lié : le message « La source a répondu 206 » était un faux diagnostic. Le contrôleur gardait le dernier statut amont même 2xx et `explainFailure` l'affichait quand la lecture échouait pour une autre raison (ici un délai). Seuls les statuts >= 400 sont maintenant retenus ; l'échec réel apparaît donc tel quel.

| Source | Via proxy | Premier affichage | Référence spike |
|---|---|---|---|
| HLS Mux (H.264) | oui | 4,9 s | 6,2 à 7,5 s |
| HLS Apple HEVC | oui | échec : délai dépassé (pas d'image) | échec |
| MP4 H.265 1080p | oui | échec : « La lecture a échoué. » | 1,6 s |
| MKV 1080p | oui | 1,7 s | 1,3 s |
| MP4 H.264 1080p | oui | 1,0 s | 1,3 s |

Reste à investiguer : le décodage HEVC (MP4 H.265 et HLS HEVC) échoue sur cette box via le proxy, cause non établie (les deux sources HEVC échouent, les H.264 passent).
