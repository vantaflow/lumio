# Spike 0.6 : moteur de torrents sur la box Android TV

Date : 2026-11-18. Box : Android 14, armeabi-v7a (32 bits), 2 Go de RAM, adb 192.168.0.43:5555.
Build : APK release `--target-platform android-arm` avec `--dart-define=LUMIO_DEBUG_TORRENT=1` (via `LUMIO_BUILD_ARGS` dans `scripts/box-smoke.sh`).
Contenu : Sintel (Blender Foundation, CC-BY), infoHash `08ada5a7a6183aae1e09d831df6748d566095a10`, trackers publics WebTorrent et UDP.

## Choix du moteur et Ruling sur la version

- `libtorrent_flutter` 2.0.0 (dernière version) est inutilisable : son Gradle télécharge les binaires natifs depuis `github.com/ayman708-UX/libtorrent_flutter/releases/...` ; ce dépôt répond 404 (supprimé ou privé). Le repli sur compilation CMake échoue (`openssl/err.h` introuvable, OpenSSL/Boost/libtorrent absents du NDK).
- Les versions 1.0.0 à 1.7.5 embarquent les `.so` précompilés dans l'archive pub.dev (armeabi-v7a incluse jusqu'à 1.7.5 ; 1.7.6 et suivantes l'omettent ou dépendent de GitHub). Ruling : **`libtorrent_flutter` épinglé à `1.7.5`** (sans `^`), même API (`addMagnet`, `getFiles`, `startStream`, `torrentUpdates`, limites de débit).
- Basculer sur `dtorrent_task_v2` n'a donc pas été nécessaire. Aucun binaire n'est téléchargé au build.
- Licence : GPL-3.0, compatible avec Lumio (GPL-3.0). `scripts/check-licenses.sh` classait à tort le texte GPL-3 comme AGPL (il cite l'AGPL à l'article 13) ; corrigé pour ne retenir que le titre.

## Verdict : GO (avec réserves)

- Le moteur tourne sur la box 32 bits, résout les métadonnées en moins de 2 s, sert un flux HTTP à plages d'octets et nettoie le disque.
- Réserve 1 : le débit est irrégulier et retombe vers 100-400 Ko/s après la salve initiale ; la moyenne de 3,1 Mbit/s suffit pour du 720p mais pas pour du 1080p à haut débit. Un seul essai sur un torrent de 129 Mo à swarm modéré : à confirmer en Task 24/25 avec lecture réelle (media_kit absent ici, mesures au niveau moteur uniquement).
- Réserve 2 : version épinglée 1.7.5 faute de binaires pour la 2.0.0 ; surveiller le projet (dépôt GitHub introuvable). Alternative de repli documentée : `dtorrent_task_v2` derrière la même interface `TorrentEngine`.
- Réserve 3 : l'APK `android-arm` contient aussi le `.so` arm64 (5,5 Mo) ; Gradle n'a pas de filtre ABI ici. Possible : `-PlibtorrentFlutterAbis` n'existe plus en 1.7.5, filtrer via `ndk.abiFilters` plus tard si la taille compte.

## Disque et taille

- Disque libre Mac : 99,03 Go avant, 95,55 Go après (environ 3,5 Go, dont le premier build Gradle/NDK complet, la tentative CMake échouée de 2.0.0 et le cache ; les binaires natifs eux-mêmes pèsent 100 Mo dans le cache pub pour 1.7.5, `.so` armeabi-v7a 3,8 Mo, arm64 5,5 Mo dans l'APK).
- APK release : 21,7 Mo.
