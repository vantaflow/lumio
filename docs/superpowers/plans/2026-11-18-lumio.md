# Lumio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire Lumio, client média Flutter compatible protocole d'addons Stremio, avec torrents, IPTV, local, Jellyfin, profils, synchro et intégrations, selon les 44 stories du plan forge.

**Architecture:** Monorepo : `packages/lumio_core` (Dart pur, toute la logique testable), `app/` (Flutter : UI Riverpod, lecteur media_kit, drift, proxy HTTP local, moteur libtorrent_flutter), `backend/` (Cloudflare Worker Hono + D1 + KV + Durable Objects). Chaque tâche suit TDD et se commite seule.

**Tech Stack:** Flutter 3.41.5 / Dart 3.11, media_kit + media_kit_video + media_kit_libs_android_video, libtorrent_flutter, flutter_riverpod, go_router, drift + sqlite3_flutter_libs, flutter_secure_storage, shelf, cryptography, http ; backend : TypeScript, Hono, Wrangler 4, vitest + @cloudflare/vitest-pool-workers.

**Spec:** `docs/superpowers/specs/2026-11-18-lumio-design.md`. Critères d'acceptation détaillés de chaque story : `~/Projects/plans/plan-client-media/stories/story-N.M.md` (chaque tâche cite sa story : ses AC sont des exigences de la tâche).

## Global Constraints

- Builds uniquement sur le Mac : `export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home`.
- Cible Android : `minSdk 24`, ABI `armeabi-v7a` pour la box (`--target-platform android-arm`), identifiant `dev.lumio.app`, nom affiché « Lumio ».
- Box de test : `adb -s 192.168.0.43:5555`. Aucune fenêtre ouverte sur le Mac : jamais `flutter run -d macos`, uniquement `dart test`, `flutter test`, builds APK.
- Disque : `scripts/disk-guard.sh` avant chaque build ; il échoue sous 80 Go libres. `build/` n'est jamais commité.
- Aucun addon pré-installé ou suggéré ; aucun scraper ni recherche de sources dans le client ; aucun visuel ou nom Stremio (« compatible protocole d'addons » seulement dans la doc).
- URL d'addons et jetons : stockés via `SecretStore`, jamais en clair dans SQLite, jamais en journal (`redactUrl` obligatoire dans tout log).
- Licence GPL-3.0 (fichier `LICENSE` à la racine).
- Interface en français par défaut, anglais disponible (gen-l10n, `app/lib/l10n/app_fr.arb`, `app_en.arb`).
- Contenus de test libres de droits uniquement (Big Buck Bunny, Sintel, distributions Linux).
- Commits terminés par la ligne `Claude-Session: https://claude.ai/code/session_01A3pSJhCBT5fjPTctwN7HeK`.

## Review Focus

1. Addon lent, JSON énorme ou malformé : l'écran ne doit jamais geler ni planter (délai 8 s, taille max 5 Mo, parse hors UI) — tests en Task 6 et 7.
2. Titres en arabe, accents et RTL dans M3U, EPG et recherche : affichage et recherche corrects — tests en Task 18 et 32.
3. Perte réseau en pleine lecture ou en plein torrent : message clair et reprise possible, pas d'écran noir figé — tests en Task 12 et 24.
4. Stockage presque plein sur la box (4,6 Go libres) : cache torrent limité, erreur « espace insuffisant » lisible — test en Task 25.
5. Même addon ajouté avec une URL légèrement différente (`/manifest.json` vs sans, majuscules d'hôte, barre finale) : pas de doublon — test en Task 6.
