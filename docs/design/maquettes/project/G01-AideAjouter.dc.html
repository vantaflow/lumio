Ajouter un addon avec son lien

1
Sur la page de l'addon, appuyez sur « Copier le lien » (ou « Install », puis « Copier l'adresse du lien »).
2
Revenez ici et collez le lien dans le champ, ou appuyez sur « Coller ».
3
Vérifiez le nom de l'addon, puis appuyez sur « Installer ».
Catalogue : choisissez un addon, puis « Installer ». Depuis le téléphone : scannez le code et collez le lien.
