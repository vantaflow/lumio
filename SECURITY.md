# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne **pas** ouvrir d'issue publique pour une faille de sécurité.

Utilisez un rapport de sécurité privé : onglet **Security** du dépôt GitHub,
puis **Report a vulnerability** (GitHub Security Advisory privé). Décrivez le
problème, la version ou le commit concerné et, si possible, les étapes pour le
reproduire.

Le projet est en développement et maintenu à titre personnel : aucun délai de
réponse n'est garanti, mais chaque rapport sera lu.

## Périmètre

Concerne : le code de ce dépôt (cœur, application, backend, scripts). Ne
concerne pas les addons tiers ni les contenus auxquels ils donnent accès.

Voir aussi [docs/securite.md](docs/securite.md).
